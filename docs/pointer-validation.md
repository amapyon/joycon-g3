# Joy-Con 姿勢・操作の検証

目的は、ひねり・左右・上下の操作を実測し、加速度・ジャイロのセンサー軸と画面への変換を確認することです。検証モードの持ち方・操作の選択は記録ラベルであり、補正方式を変更しません。

## 設定と測定

1. 更新後のアプリを再起動し、R Joy-Con を接続する。
2. 平らな場所で静止させてキャリブレーションを完了する。
3. 補正方式「重力基準（自動）」、Speed `0.05`、Deadzone `120` にする。
4. 「姿勢・操作の検証モード」を有効にし、対象「R（右）」を選ぶ。ポインター非表示でも受信中と表示されることを確認する。
5. 持ち方・操作を選び、メモに握り方（ボタン面・先端の向き）、実際のポインターの動きを記載する。
6. 「2秒後から5秒記録」を押す。2秒の準備後、選択した操作だけを行う。往復せず、同じ方向の操作を記録する。
7. 記録ごとに「JSON保存」する。結果をコピーしてチャットへ貼り付けることもできる。次の記録開始で前回の記録は置き換わる。

最初に通常持ちで、静止、左、右、上、下、左ひねり、右ひねりを別々に測定します。その後、左・右へ45°または90°ひねって保持した姿勢で、左右・上下を測定します。

非表示の影響は「非表示でひねる→表示して左右へ振る」「非表示でひねる→表示して上下へ振る」を使います。ボタンを離してひねり、その姿勢のままボタンを押し、向きを変えます。各サンプルに実際の表示状態が残ります。

## 値の意味

- 生加速度・生ジャイロ: センサーから読んだ3軸値。軸の対応を推測する前にこの値を確認する。
- 加速度(G)・角速度(°/s): 現在のコードの換算係数による値。角速度はジャイロバイアスを除く。
- 推定重力・縦回転軸: 左右のセンサー向きを揃えた共通本体座標の単位ベクトル。生値の座標とは異なる。
- 閾値前の画面成分: 保持姿勢を補正した後、デッドゾーンを適用する前の横(Z)・縦(Y)成分。
- 閾値後の画面成分: デッドゾーン適用後の横・縦成分。
- 予定移動: 表示中と仮定した移動量。方向符号と速度を適用した論理ピクセル値。
- 実移動: 表示状態・キャリブレーション・画面端の制限を反映した、main プロセスの座標差分。描画側のスムージング後の測定値ではない。非表示中は0。

静止時はジャイロの残留値、ひねり時は反応する生ジャイロ軸と閾値前の画面成分、保持姿勢変更時は生加速度と推定重力の差を比較します。生値にひねりが出た時点でセンサー軸を特定し、補正後に横・縦へ混入する段階を調べます。

## 加速度換算修正後の再検証

加速度は `1/4096` で G に換算します。静止時の大きさが約1Gであることを確認してください。旧記録の `1/16384` 換算では約0.25Gとなり、重力方向の補正が無効になっていました。検証表示と実処理は同じ換算定数を使用します。

キャリブレーション成功時は古いポインター姿勢を破棄し、次の有効な加速度から重力方向を初期化します。一連の測定前に1回、台に置いて静止した状態で実施し、完了表示を確認してください。姿勢を変えるたびの再実施は不要です。

1. アプリを再起動し、Rを接続してキャリブレーションを完了する。
2. 補正方式「重力基準（自動）」、Speed `0.05`、Deadzone `120`、対象「R（右）」にする。
3. 通常姿勢で約2秒静止し、ポインターを表示して検証欄が「表示」であることを確認する。
4. 「2秒後から5秒記録」を押し、準備中は静止する。
5. 記録開始後、左右または上下へ20〜30°程度、1〜2秒かけて一方向へ向ける。その後は記録終了まで静止し、元へ戻すのは終了後にする。
6. 左・右・上・下を別々に保存し、画面上で動いた方向をメモする。ポインター位置に合わせて手の動きを変える必要はない。画面端に到達した場合はメモする。
7. 通常姿勢で追従を確認した後、非表示で左または右へ90°ひねり、約2秒保持してから表示する。その姿勢で左右・上下を同じ手順で記録する。
8. ひねりだけの測定は別記録にし、先端の向きをなるべく保ちながら長手方向の軸を中心に回す。

自動テストでは左右・上下の実測4記録を再生し、ずれた重力推定から準備時間中に復帰した後、移動方向と他軸への混入を検証します。これは実機での操作確認を代替するものではありません。

データ受信が途切れた場合は最終値であることを表示します。キャリブレーション中は姿勢更新が停止するため、補正値は参考値として表示・記録します。記録はブラウザー内のメモリーに保持し、持ち方・操作などの設定だけを localStorage に保存します。
